## 개념: 질량 비율을 원자 수 비율로

원소 분석을 하면 "탄소 40%, 수소 6.7%..."처럼 질량 비율이 나옵니다. 하지만 화학식은 원자 **개수**의 비율이므로, 각 원소의 질량을 몰수로 바꿔야 합니다. 이렇게 얻은 가장 간단한 정수비가 실험식이고, 실제 분자는 실험식의 정수배라서 몰질량을 알면 분자식이 정해집니다.

## 핵심 공식

1. 시료 $100\ \text{g}$ 가정 → 백분율 = 질량(g)
2. 각 원소 몰수 $n = \dfrac{m}{M}$
3. 가장 작은 몰수로 나눠 정수비 → 실험식
4. $\dfrac{\text{몰질량}}{\text{실험식량}} = k$ → 분자식은 실험식 × $k$

## 예제

<Example>
어떤 화합물이 질량으로 C 40.0%, H 6.7%, O 53.3%이고, 몰질량이 $180\ \text{g/mol}$입니다. 실험식과 분자식을 구하세요. (C 12.01, H 1.008, O 16.00)
</Example>

## 단계별 해설

<Step n={1} title="몰수로 바꾼다">
$$
n_C = \frac{40.0}{12.01} = 3.33,\quad n_H = \frac{6.7}{1.008} = 6.65,\quad n_O = \frac{53.3}{16.00} = 3.33
$$
</Step>

<Step n={2} title="가장 작은 값으로 나눈다">
$3.33$으로 나누면 C : H : O $= 1 : 2.00 : 1$. 실험식은 $\text{CH}_2\text{O}$.
</Step>

<Step n={3} title="실험식량과 비교한다">
$\text{CH}_2\text{O} = 12.01 + 2(1.008) + 16.00 = 30.03$. $\dfrac{180}{30.03} \approx 6$.
</Step>

<Step n={4} title="분자식">
$(\text{CH}_2\text{O})_6 = \text{C}_6\text{H}_{12}\text{O}_6$ (포도당).
</Step>

<Answer>
실험식 $\text{CH}_2\text{O}$, 분자식 $\text{C}_6\text{H}_{12}\text{O}_6$
</Answer>

## 자주 하는 실수

<Mistake title="질량 비를 그대로 원자 수 비로 쓴다">
40 : 6.7 : 53.3을 정수비로 줄이면 전혀 다른 식이 나옵니다. 반드시 몰수로 바꾸세요.
</Mistake>

<Mistake title="1.5, 2.33 같은 값을 반올림한다">
1.5는 2를 곱해 3, 2.33은 3을 곱해 7로 만들어야 합니다. 1.5를 2로 반올림하면 틀립니다.
</Mistake>

<Mistake title="중간 계산에서 너무 일찍 반올림한다">
몰수는 유효숫자 3~4자리를 유지한 뒤 마지막 비율에서 판단하세요.
</Mistake>

## 유사 연습 문제

<Practice n={1}>
<Fragment slot="problem">
질량으로 N 30.4%, O 69.6%이고 몰질량이 약 $92\ \text{g/mol}$인 화합물의 분자식은?
</Fragment>

$n_N = \frac{30.4}{14.01} = 2.17$, $n_O = \frac{69.6}{16.00} = 4.35$ → 1 : 2, 실험식 $\text{NO}_2$ (46.01). $\frac{92}{46.01} = 2$.

**정답:** $\text{N}_2\text{O}_4$
</Practice>

## 개념: 주기 신호를 주파수별로 나누기

악기 소리, 교류 전압, 회전체의 진동처럼 반복되는 신호는 서로 다른 주파수의 사인파·코사인파를 더한 것으로 볼 수 있습니다. 푸리에 급수는 주기함수를 $\cos nx$, $\sin nx$ ($n = 1, 2, 3, \ldots$)의 합으로 쓰고, 각 주파수 성분이 얼마나 들어 있는지를 계수로 구합니다.

계수를 구할 수 있는 이유는 **직교성** 때문입니다. 한 주기 동안 $\sin mx\sin nx$ 같은 곱을 적분하면 $m \neq n$일 때 $0$이 되므로, 원하는 항 하나만 골라낼 수 있습니다. 이 아이디어가 이후 편미분방정식(열·파동 방정식)의 변수분리 풀이와 푸리에 변환으로 이어집니다.

## 핵심 공식

주기 $2\pi$인 함수 $f(x)$에 대해

$$
f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\big(a_n\cos nx + b_n\sin nx\big)
$$

$$
a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx \ (n \ge 0), \qquad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx
$$

- $f$가 **기함수**면 $a_n = 0$, $b_n = \dfrac{2}{\pi}\displaystyle\int_0^{\pi} f(x)\sin nx\,dx$
- $f$가 **우함수**면 $b_n = 0$, $a_n = \dfrac{2}{\pi}\displaystyle\int_0^{\pi} f(x)\cos nx\,dx$
- 유용한 값: $\cos n\pi = (-1)^n$, $\sin n\pi = 0$

## 예제

<Example>
$f(x) = x$ ($-\pi \lt x \lt \pi$)를 주기 $2\pi$로 확장한 함수의 푸리에 급수를 구하고, 이를 이용해 $1 - \dfrac13 + \dfrac15 - \dfrac17 + \cdots$의 값을 구하세요.
</Example>

## 단계별 해설

<Step n={1} title="대칭성을 확인한다">
$f(-x) = -x = -f(x)$이므로 기함수입니다. 따라서 $a_0 = a_n = 0$이고 사인항만 구하면 됩니다.
</Step>

<Step n={2} title="bₙ을 부분적분으로 구한다">
$$
b_n = \frac{2}{\pi}\int_0^{\pi} x\sin nx\,dx
$$

$u = x$, $dv = \sin nx\,dx$로 두면

$$
\int_0^{\pi} x\sin nx\,dx = \Big[-\frac{x\cos nx}{n}\Big]_0^{\pi} + \frac{1}{n}\int_0^{\pi}\cos nx\,dx = -\frac{\pi\cos n\pi}{n} + 0 = \frac{\pi(-1)^{n+1}}{n}
$$

따라서 $b_n = \dfrac{2(-1)^{n+1}}{n}$ 입니다.
</Step>

<Step n={3} title="급수를 쓴다">
$$
x = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots\right) \qquad (-\pi \lt x \lt \pi)
$$
</Step>

<Step n={4} title="연속인 점을 골라 대입한다">
$x = \dfrac{\pi}{2}$를 넣으면 $\sin\dfrac{n\pi}{2}$는 $1, 0, -1, 0, 1, \ldots$ 이므로

$$
\frac{\pi}{2} = 2\left(1 - \frac13 + \frac15 - \frac17 + \cdots\right)
\quad\Longrightarrow\quad
1 - \frac13 + \frac15 - \cdots = \frac{\pi}{4}
$$
</Step>

<Step n={5} title="불연속점도 확인한다">
$x = \pi$에서 확장된 함수는 $\pi$에서 $-\pi$로 뜁니다. 급수는 모든 항이 $0$이 되어 $0$을 주는데, 이는 좌극한 $\pi$와 우극한 $-\pi$의 평균과 같습니다.
</Step>

<Answer>
$x = \displaystyle\sum_{n=1}^{\infty}\frac{2(-1)^{n+1}}{n}\sin nx$ ($-\pi \lt x \lt \pi$), $\quad 1 - \dfrac13 + \dfrac15 - \cdots = \dfrac{\pi}{4}$
</Answer>

## 자주 하는 실수

<Mistake title="상수항을 a₀로 쓴다">
위 공식에서 상수항은 $\frac{a_0}{2}$입니다. $a_0$를 $a_n$과 같은 공식으로 구하기 위해 2로 나눠 둔 것입니다. 교재마다 $a_0$의 정의가 다르니 쓰는 공식의 상수항 형태를 확인하세요.
</Mistake>

<Mistake title="cos nπ를 1로 둔다">
$\cos n\pi = (-1)^n$입니다. 이걸 $1$로 두면 부호가 번갈아 바뀌는 계수가 모두 같은 부호가 됩니다.
</Mistake>

<Mistake title="대칭성을 쓰지 않고 모든 계수를 적분한다">
기함수·우함수를 먼저 확인하지 않으면 $0$이 될 적분을 길게 계산하게 됩니다. 시험에서는 시간 손실이 큽니다.
</Mistake>

<Mistake title="불연속점에서 원래 함수값과 같다고 쓴다">
푸리에 급수는 불연속점에서 좌우 극한의 평균으로 수렴합니다. 급수 합을 구하려고 값을 넣을 때는 연속인 점을 고르세요.
</Mistake>

## 유사 연습 문제

<Practice n={1}>
<Fragment slot="problem">
$f(x) = |x|$ ($-\pi \lt x \lt \pi$)의 푸리에 계수를 구하세요.
</Fragment>

우함수이므로 $b_n = 0$. $a_0 = \dfrac{2}{\pi}\displaystyle\int_0^\pi x\,dx = \pi$, $a_n = \dfrac{2}{\pi}\displaystyle\int_0^\pi x\cos nx\,dx = \dfrac{2\big((-1)^n - 1\big)}{\pi n^2}$ 입니다. 짝수 $n$이면 $0$, 홀수 $n$이면 $-\dfrac{4}{\pi n^2}$.

**정답:** $|x| = \dfrac{\pi}{2} - \dfrac{4}{\pi}\left(\cos x + \dfrac{\cos 3x}{9} + \dfrac{\cos 5x}{25} + \cdots\right)$
</Practice>

<Practice n={2}>
<Fragment slot="problem">
$0 \lt x \lt \pi$에서 $1$, $-\pi \lt x \lt 0$에서 $-1$인 구형파의 푸리에 급수를 구하세요.
</Fragment>

기함수이므로 $b_n = \dfrac{2}{\pi}\displaystyle\int_0^\pi \sin nx\,dx = \dfrac{2\big(1 - (-1)^n\big)}{n\pi}$ 입니다. 홀수 $n$에서만 $\dfrac{4}{n\pi}$.

**정답:** $\dfrac{4}{\pi}\left(\sin x + \dfrac{\sin 3x}{3} + \dfrac{\sin 5x}{5} + \cdots\right)$
</Practice>

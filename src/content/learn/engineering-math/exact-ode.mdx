## 개념: 어떤 함수의 전미분이 0이라는 뜻

함수 $F(x, y)$의 전미분은 $dF = F_x\,dx + F_y\,dy$ 입니다. 미분방정식 $M\,dx + N\,dy = 0$이 바로 어떤 $F$의 전미분이라면, $dF = 0$이므로 $F$는 상수입니다. 즉 해는 $F(x, y) = C$라는 곡선들입니다. 이런 $F$가 있는지는 혼합 편미분이 같다는 조건($F_{xy} = F_{yx}$)으로 판정합니다. 물리의 보존력과 퍼텐셜 에너지가 같은 구조입니다.

## 핵심 공식

$$
\text{완전성:}\quad \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}
$$

$$
F = \int M\,dx + g(y), \qquad \frac{\partial F}{\partial y} = N\ \text{에서}\ g'(y)\ \text{결정}, \qquad \text{해: } F(x,y) = C
$$

## 예제

<Example>
$(2xy + 3)\,dx + (x^2 + 4y)\,dy = 0$, $y(1) = 1$을 푸세요.
</Example>

## 단계별 해설

<Step n={1} title="완전한지 판정한다">
$M = 2xy + 3$, $N = x^2 + 4y$. $\dfrac{\partial M}{\partial y} = 2x$, $\dfrac{\partial N}{\partial x} = 2x$ 로 같으므로 완전 미분방정식입니다.
</Step>

<Step n={2} title="M을 x로 적분한다">
$$
F = \int(2xy + 3)\,dx = x^2y + 3x + g(y)
$$

$y$는 상수 취급이라 적분상수 자리에 $y$의 함수 $g(y)$를 둡니다.
</Step>

<Step n={3} title="N과 비교해 g(y)를 정한다">
$\dfrac{\partial F}{\partial y} = x^2 + g'(y) = x^2 + 4y$ 이므로 $g'(y) = 4y$, $g(y) = 2y^2$.

$$
F(x, y) = x^2y + 3x + 2y^2
$$
</Step>

<Step n={4} title="초기값으로 C를 정한다">
$F(1, 1) = 1 + 3 + 2 = 6$ 이므로 해는 $x^2y + 3x + 2y^2 = 6$ 입니다.
</Step>

<Answer>
$x^2 y + 3x + 2y^2 = 6$
</Answer>

## 자주 하는 실수

<Mistake title="완전성 판정에서 미분 변수를 바꾼다">
$M$은 $y$로, $N$은 $x$로 미분합니다. 반대로 하면 판정이 틀립니다.
</Mistake>

<Mistake title="g(y) 대신 상수 C를 붙인다">
$M$을 $x$로 적분할 때 사라진 것은 $x$에 대한 상수, 즉 $y$의 함수일 수 있습니다. $C$만 붙이면 $4y$ 같은 항을 놓칩니다.
</Mistake>

<Mistake title="F를 구하고 F = 0으로 쓴다">
해는 $F = C$입니다. 상수를 빼먹으면 초기값을 맞출 수 없습니다.
</Mistake>

## 유사 연습 문제

<Practice n={1}>
<Fragment slot="problem">
$(y\cos x + 2x)\,dx + (\sin x - 1)\,dy = 0$의 일반해를 구하세요.
</Fragment>

$M_y = \cos x = N_x$ 로 완전합니다. $F = y\sin x + x^2 + g(y)$, $F_y = \sin x + g'(y) = \sin x - 1$에서 $g = -y$.

**정답:** $y\sin x + x^2 - y = C$
</Practice>
